# Proyecto 2 — Análisis de pasajeros del Titanic

## Descripción
Proyecto de análisis de datos exploratorio enfocado en la información de los pasajeros del Titanic para identificar características asociadas con la supervivencia, aplicando buenas prácticas de reproducibilidad, control de versiones con Git y entornos virtuales de Python.

## Dataset
* **Nombre:** Titanic — Kaggle (train.csv)
* **Fuente:** [Kaggle - Titanic Dataset](https://www.kaggle.com/c/titanic/data)
* **Descripción:** Contiene datos detallados sobre los pasajeros a bordo del Titanic, incluyendo clase, género, edad, tarifa pagada y si sobrevivieron o no.

## Objetivo
Realizar limpieza, preprocesamiento, análisis estadístico y visualización de datos para responder preguntas clave sobre los factores de supervivencia, sin implementar modelos de Machine Learning.

## Requisitos
* Python 3.x
* Dependencias especificadas en `requirements.txt`
